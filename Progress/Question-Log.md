### Q1 — 04-Binary-Search / 0875 Koko Eating Bananas — Pattern recognition

> 題目：給定香蕉堆 piles 與欄截時數 h，每小時只能挑一堆以速度 k 吃（吃不滿也用掉那小時），求能在 h 小時內吃完的最小 k。這題的主要技巧是？

| # | 選項 | 描述 |
| - | ---- | ---- |
| A | 排序後貪心分配 | 將 piles 由大到小排序，依序決定每堆花多少小時 |
| B | 單調佇列維護區間最大值 | 用 deque 在滑動過程中維持堆的極值 |
| **C** | **在 1..max(piles) 上二分** ✅ | 對「速度 k」的可能取值範圍做二分搜尋 |
| D | 前綴和加 hash map | 累計每堆所需時數後用 hash 查找符合條件的區間 |

- 使用者答案：**C** — ✅ pass
- 備註：題幹「欄截時數」是筆誤，原意為「上限時數 h」；日後重用請修正。

### Q2 — 05-Sliding-Window / 0239 Sliding Window Maximum — Key insight

> 0239 Sliding Window Maximum 的單調遞減 deque，新元素 nums[i] 入隊前會把隊尾所有 ≤ nums[i] 的元素彈掉。為什麼這些元素可以直接丟掉？

| # | 選項 | 描述 |
| - | ---- | ---- |
| **A** | **它們比 nums[i] 早出窗，值又不大於 nums[i]** ✅ | 以索引與數值兩個層面同時考慮這些元素的處境 |
| B | deque 必須保持有序才能對它二分搜尋 | 查詢最大值時需要在 deque 上做 O(log k) 查找 |
| C | 它們的索引已經超出當前窗口左界 | 索引小於 i - k + 1 的元素不再屬於當前窗口 |
| D | deque 容量上限是 k，必須先騰出位置 | 窗口大小固定，容器內元素數不能超過 k |

- 使用者答案：**A** — ✅ pass

### Q3 — 03-Stack / 0739 Daily Temperatures — Output prediction

附上的程式碼片段（彈出條件被改成 `<=`）：

```cpp
// temperatures = [30, 30, 41]
vector<int> dailyTemperatures(vector<int>& t) {
  int n = t.size();
  vector<int> ans(n);
  stack<int> waiting;
  for (int i = 0; i < n; ++i) {
    while (!waiting.empty() && t[waiting.top()] <= t[i]) {   // 注意這個比較
      int j = waiting.top(); waiting.pop();
      ans[j] = i - j;
    }
    waiting.push(i);
  }
  return ans;
}
```

> 上面那段 dailyTemperatures（彈出條件寫成 `<=`），輸入 `[30, 30, 41]` 時回傳什麼？

| # | 選項 | 描述 |
| - | ---- | ---- |
| A | `[2, 1, 0]` | 第一天等 2 天、第二天等 1 天 |
| B | `[2, 2, 0]` | 前兩天都等 2 天 |
| C | `[1, 2, 0]` | 第一天等 1 天、第二天等 2 天 |
| **D** | **`[1, 1, 0]`** ✅ | 前兩天都等 1 天 |

- 使用者答案：**看不懂**（無法手動模擬 stack 的 push／pop）— ❌ **lapse**
- 處置：逐格 trace 講解 + `g++ -std=c++20` 實跑驗證（`<=` 版得 `[1,1,0]`、`<` 版得 `[2,1,0]`），再出 Q3b 補測。

### Q4 — 17-Bit-Manipulation / 0338 Counting Bits — Key insight

> 對於任意正整數 n，運算 `n & (n - 1)` 的效果是？

| # | 選項 | 描述 |
| - | ---- | ---- |
| A | 取出最右側的 1，其餘位清零 | 結果是一個只有單一 bit 為 1 的數 |
| **B** | **把最右側的 1 清成 0** ✅ | 結果比 n 少一個 1-bit |
| C | 把最左側的 1 清成 0 | 結果比 n 少一個 1-bit |
| D | 把 n 的所有位元反轉後加一 | 等價於一個取補數運算 |

- 使用者答案：**B** — ✅ pass
